# Bikeshare Data Analysis

This project analyzes bikeshare usage data from different cities and provides statistics based on user-selected filters such as city, month, and day.

## Information about how to use your project

### Requirements

- Python 3
- Pandas

### Usage

Run the bikeshare_starter.py script and follow the prompts to select a city, month, and day.

Features: 
- Filter data by city
- Filter data by month
- Filter data by day
- Display bikeshare statistics
